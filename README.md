# QSO Practice Project

## About the Project

The QSO Practice Project is a simple multi-page website created to practise HTML5, website navigation, and basic web development. It introduces the author and presents information about learning projects and contact options.

## Files and Directories

- `README.md` — Explains the project, its files, and its author.
- `index.html` — The home page introducing the website.
- `about.html` — Provides information about the author and learning goals.
- `projects.html` — Describes web development practice projects.
- `contact.html` — Provides general contact information.
- `images/` — Stores images used on the website.
- `css/` — Stores stylesheets for the website's appearance.
- `js/` — Stores JavaScript files for interactive features.
